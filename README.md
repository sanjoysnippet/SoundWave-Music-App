
# 🎵 SoundWave – Music Streaming App

SoundWave is a modern full-stack music streaming application inspired by Spotify. Users can explore music, listen to tracks, upload songs, and enjoy a smooth music streaming experience.

## 🚀 Features

- User Registration and Login
- Music Streaming and Audio Playback
- Upload Music Tracks
- Browse and Search Music
- Responsive User Interface
- Backend API Integration
- User Authentication

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- REST API

## ⚙️ Installation and Setup

### 1. Clone Repository

```bash
git clone https://github.com/sanjoysnippet/SoundWave-Music-App.git
cd SoundWave-Music-App
```

### 2. Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder and add the environment variables required by your backend configuration.

Start the backend using the start script defined in `backend/package.json`.

### 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL shown in your terminal.

## 🔐 Environment Variables

Keep your environment variables and secret keys private. Never upload `.env` files to GitHub.
